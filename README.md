# Lumiel Jumpscare Tools

Foundry VTT 13.351.

## Запуск

1. Включите модуль и обновите страницу.
2. Откройте макрос **Lumiel · Скримеры** или панель в настройках модуля.
3. Создайте скример, выберите файл, звук и игроков.
4. Нажмите **Предзагрузка**, дождитесь статуса **Готов**, затем **Запустить**.

## Кнопки и поля

- **Загрузить**: выбрать файл или загрузить с компьютера.
- **Сохранить**: сохранить настройки.
- **Только мне**: предпросмотр у ГМа.
- **Предзагрузка**: загрузить всю цепочку всем игрокам онлайн.
- **Запустить**: показать выбранным игрокам.
- **Остановить у всех**: прервать показ и цепочку.
- **Следом по очереди**: добавить следующие скримеры и задать их порядок.
- **Завершение**: по крестику или по таймеру. Таймер использует поле **Длительность**.
- **×** или **Escape**: закрыть текущий показ.

Каждый следующий скример появляется после завершения предыдущего. Если у него есть своя очередь, она проигрывается первой. После изменения файлов или очереди повторите предзагрузку.

## Медиа

Поддерживаются изображения, GIF, MP4 и WebM. Видео проигрывается без панели управления. Если выбран отдельный звук, встроенное аудио видео отключается.

## Фокси

Включите **Фокси** и выберите вариант: **FNAF 1**, **FNAF 2**, **FNAF 4**, **Sister Location** или **FNAF 6**. Параметры закреплены; следующие скримеры можно добавлять в очередь. Фон Foundry затемняется на 75%.

## Игрокам

**Настройки → Lumiel Jumpscare Tools → Показывать мне скримеры**. По умолчанию включено. Отключение прекращает показ и звук.

## Макрос

```js
game.modules.get("lumiel-jumpscare-tools").api.openPanel();
```
